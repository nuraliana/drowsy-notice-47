The one-line resignation letter of a cron job, written by the cron job itself.

> I resign. Twice a year you move the clocks and file a ticket saying I am late, as if I owned the sun.

`main.py` writes that line, byte-exact and with no trailing newline, to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `./output` when the variable is unset).

A one-line resignation letter from a cron job that gets blamed for being late every time the clocks move.

Running `main.py` writes the letter to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), byte-exact with no trailing newline.
